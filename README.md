# Nexora — AI Platform Landing Page Concept

> A self-initiated, front-end concept for a fictional enterprise AI platform.

Nexora is a polished landing page concept created to demonstrate modern front-end development, responsive layout, interactive motion, bilingual content, and an enterprise SaaS visual system. The company, metrics, testimonials, and business claims shown in the interface are fictional demonstration content.

## Live Demo

[Open the live website](https://quiet-kheer-cd4e19.netlify.app/)

## Features

- Responsive enterprise SaaS landing page.
- English and Arabic language toggle.
- Hero section, navigation menus, calls to action, capability sections, product showcase, platform metrics, technology ecosystem, comparison section, and newsletter form.
- Interactive canvas cursor trail and animated visual elements.
- Modular page content with client-side interactions.
- Dark visual system with gradients, cards, hover states, and responsive sections.

## Technology Stack

| Area | Technology |
|---|---|
| Framework | Next.js 14 |
| UI | React 18 |
| Language | TypeScript and JavaScript |
| Visual effects | Three.js and Canvas API |
| Styling | Custom CSS |
| Deployment | Netlify |

## Local Setup

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in a browser. For a production build:

```bash
npm run build
npm run start
```
